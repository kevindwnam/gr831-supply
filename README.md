# GR831 약술형논술 콘텐츠 공급 가맹

> GR831약술형논술연구소의 B2B 콘텐츠 공급 가맹 안내 사이트
> 학원 원장을 타겟으로 한 반응형 모바일+PC 사이트

## 핵심 셀링 포인트

- **가천대 자문위원 출신 연구진** — 6년차 약술형논술 전문 기관
- **3년 연속 합격생 증가** — 98 → 120 → 135명 (2026학년도 기준)
- **수학 90% / 국어 80% 출제 적중률**
- **회당 19,400원 · 가입비 없음 · 비과세** — 낮은 진입장벽
- **47회 모의고사 + 5대 자료 + 매일국어 + 학습웹 + 채점 + 성적표** 통합 공급
- **본사 직접 채점 · 매주 금요일 성적표 자동 발송**
- **전국 통일 회차 → 전국 수강생 평균 비교 가능**

## 페이지 구조

| 라우트 | 페이지명 | 주요 내용 |
|---|---|---|
| `/` | 홈 | Hero + 6개 메뉴 카드 + 하단 CTA |
| `/about` | GR831 소개 | 자문위원 연구진 · 3개년 합격 실적 · 본사 역할 4가지 |
| `/content` | 공급 콘텐츠 ⭐ | 47회 모의고사 · 적중률 · 지류/학습웹 · 매일국어 · 학습웹 · 성적표 |
| `/operation` | 운영 방식 | 통일 회차 · 주간 흐름 · 역할 분담 · 채점 사이클 |
| `/revenue` | 수익 구조 | 정산 금액 · 시뮬레이션 · 포함 콘텐츠 |
| `/process` | 진행 절차 | 상담~개시 6단계 |
| `/contract` | 계약 조건 | 계약 기간 · 환불 · 위약 + 계약서 전문 토글 |

## 기술 스택

- **Next.js 16** (App Router, 정적 생성)
- **TypeScript**
- **Tailwind CSS v4** (CSS-first config, brand-* 컬러 토큰)
- **Noto Serif KR** (next/font/google) + **Pretendard** (CDN)
- **Vercel** 배포
