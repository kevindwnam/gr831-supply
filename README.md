# GR831 약술형논술 콘텐츠 공급 가맹

GR831약술형논술연구소의 B2B 콘텐츠 공급 가맹 안내 사이트입니다.
학원 원장을 대상으로 하며, **모바일 + PC 반응형**으로 제작되었습니다.

## 기술 스택

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Vercel 배포

## 실행 방법

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인할 수 있습니다.

## 빌드

```bash
npm run build
```
